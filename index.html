Bring your own key

Paste a YouTube Data API v3 key to load real Shorts. It's saved only in this browser and sent only to Google.

If every video says it can't play, serve this file from localhost (python -m http.server) instead of opening it directly. YouTube blocks embeds from file:// pages.
